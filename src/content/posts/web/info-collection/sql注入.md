## 三、知识要点速查

### 1. 注入本质

用户输入被拼进 SQL，导致「数据」变成「代码」：

```sql
-- 开发者本意
SELECT * FROM users WHERE id = '$id';

-- 攻击者输入：1' OR '1'='1
SELECT * FROM users WHERE id = '1' OR '1'='1';
```

### 2. 注入分类

| 类型     | 特征              | 典型手法                     |
| -------- | ----------------- | ---------------------------- |
| 数字型   | 参数无引号包裹    | `id=1 OR 1=1`                |
| 字符型   | 参数有引号        | `id=1' OR '1'='1`            |
| 搜索型   | LIKE '%xx%'       | `%' OR 1=1-- `               |
| 鉴权型   | 登录框            | `' OR 1=1-- `                |
| 联合注入 | 有回显列          | `UNION SELECT`               |
| 报错注入 | 页面回显 SQL 错误 | `updatexml` / `extractvalue` |
| 布尔盲注 | 真假页面不同      | `AND LENGTH(database())=N`   |
| 时间盲注 | 真假响应时间不同  | `AND IF(条件,SLEEP(3),0)`    |
| 堆叠注入 | 可多语句          | `'; DROP ...`                |
| 二次注入 | 入库后再拼接      | 注册恶意数据再触发           |

### 3. 标准信息收集顺序（联合/报错/盲注通用）

1. 确认注入点与闭合
2. 判断列数（`ORDER BY n`）
3. 找回显位（`UNION SELECT 1,2,3...`）
4. 爆库名 → 表名 → 列名 → 数据
5. MySQL 常用：
   - `database()` / `user()` / `version()`
   - `information_schema.tables`
   - `information_schema.columns`
   - `group_concat()`

### 4. 常见过滤绕过思路

| 过滤点               | 绕过思路                   |
| -------------------- | -------------------------- |
| 空格                 | `/**/` `%09` `%0a` `()`    |
| `and`/`or`           | `&&` `\|\|` `\|` 双写      |
| `union`/`select`     | 大小写混写、双写、内联注释 |
| `information_schema` | `sys` 库视图、无列名注入   |
| 等号 `=`             | `LIKE` `REGEXP` `<>` 组合  |
| 引号                 | 十六进制 `0x...`、`CHAR()` |

### 5. 防御要点（理解攻击也要懂防御）

- 预编译 / 参数化查询（首选）
- ORM 正确用法
- 最小权限数据库账号
- 关闭详细报错（生产）
- WAF 只能辅助，不能替代安全编码

## 四、实操检查清单（每道题都过一遍）

- [ ] 单引号 `'` 是否报错/异常
- [ ] 数字型还是字符型
- [ ] 注释符是 `-- ` 还是 `#`
- [ ] GET / POST / Cookie / Header 哪个可控
- [ ] 有无回显、有无报错、有无时间差
- [ ] 有无关键字过滤（空格、or、union…）
- [ ] 数据库类型（MySQL 为主）
